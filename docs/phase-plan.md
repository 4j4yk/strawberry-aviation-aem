# Delivery phases and acceptance

| Phase | Deliverable | Current repository status |
| --- | --- | --- |
| 0 | Independent repository, architecture boundaries and budgets | Implemented; GitHub publication pending |
| 1 | Flightline design tokens, motion loader and authorable block shells | Implemented locally |
| 2 | Live Mage-OS catalog through a bounded GraphQL gateway | Deployed and verified with live Mage-OS data |
| 3 | Dated static fallback with transactions disabled | Implemented and source-contract verified; forced-outage verification pending |
| 4 | Secure product handoff to the Mage-OS reference storefront | Live gateway URLs verified; published AEM handoff pending |
| 5 | Compatibility, exploded part, AOG timeline and architecture motion blocks | Implemented; authored media/content pending |
| 6 | Accessibility, performance, CORS, uptime and production evidence | CORS and gateway health verified; AEM publication evidence pending |

No phase is accepted solely because source code exists. Publication, content authoring and live verification remain
separate gates. The automotive `aem-demo` repository and domain are explicitly outside this project.
